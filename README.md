## Guía de Controles
* **Movimiento:** Teclas `W`, `A`, `S`, `D` / Flechas de dirección
* **Salto:** Barra espaciadora (`Space`)
* **Interacción:** Tecla `E` y Q
* **Correr:** Tecla Shift
* **PowerInvisivilidad:** muse derecho o isquierdo
